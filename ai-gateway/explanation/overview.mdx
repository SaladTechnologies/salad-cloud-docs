## What is Salad AI Gateway?

Salad AI Gateway is a managed LLM API service that gives you direct access to powerful open-source models through a
single, OpenAI-compatible endpoint - with no infrastructure to deploy or manage. It is powered by SaladCloud's
distributed GPU network, bringing the same cost-efficiency of self-hosted models with the simplicity of a hosted API.

Any tool or library that supports a custom base URL - Aider, OpenCode, OpenClaw, Cline, Cursor, Goose, Vercel AI SDK,
and more - works with Salad AI Gateway out of the box.

## API Endpoint

```
https://ai.salad.cloud/v1
```

## Access Model

- **Pay per token:** Self-service access with an AI Gateway key belonging to one user and one organization. Requests are
  billed to that organization's credits; a positive balance is required to admit new requests.
- **Closed beta:** The existing allowlisted flat-rate path remains available to approved users under their monthly plan,
  without per-token charges. [Contact Support](/support/contact) for questions about an existing plan.

The setup examples on this page use the pay-per-token path and its organization-specific AI Gateway key.

## Billing

Pay-per-token requests use the [published input and output token rates](/ai-gateway/reference/pricing), with no
concurrency limit. Usage draws from the credit balance of the organization associated with your key. Requests already
admitted complete and are billed even if credits run out during generation or the key is revoked or regenerated.

Follow [Pay-Per-Token Onboarding](/ai-gateway/tutorials/pay-per-token-onboarding) to add credits and create your AI
Gateway API key.

## Quick Start

The API follows the OpenAI `v1/chat/completions` format. Send requests using your organization-specific AI Gateway API
key in the `Authorization` header. This is not the account API key used with `Salad-Api-Key`:

```bash
export SALAD_AI_GATEWAY_API_KEY="<your-ai-gateway-api-key>"

curl https://ai.salad.cloud/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $SALAD_AI_GATEWAY_API_KEY" \
  -d '{
    "model": "qwen3.6-35b-a3b",
    "messages": [
      {"role": "user", "content": "Explain distributed GPU computing in one paragraph."}
    ]
  }'
```

Replace `<your-ai-gateway-api-key>` with the key created for the organization you want to bill.

## Use with OpenAI-Compatible Tools

Because Salad AI Gateway exposes a standard OpenAI-compatible endpoint, you can use it with any tool that supports a
custom base URL.

We have integration guides for many popular agentic tools - Cline, Aider, OpenCode, OpenClaw, Kilo Code, Roo Code,
Continue, Goose, Hermes Agent, and more. In guides with both backends, follow the **Salad AI Gateway** tab. Self-hosted
Container Engine deployments use different endpoints and authentication. For AI Gateway, set your organization-specific
AI Gateway key in the tool's API key field (sent as `Authorization: Bearer`) and point the base URL to
`https://ai.salad.cloud/v1`. Do not add a `Salad-Api-Key` custom header.

**Python (openai SDK):**

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://ai.salad.cloud/v1",
    api_key=os.environ["SALAD_AI_GATEWAY_API_KEY"],
)

response = client.chat.completions.create(
    model="qwen3.6-35b-a3b",
    messages=[{"role": "user", "content": "Hello from Salad AI Gateway!"}],
)
print(response.choices[0].message.content)
```

**Environment variables (for tools like Aider, etc.):**

```bash
export OPENAI_BASE_URL=https://ai.salad.cloud/v1
export OPENAI_API_KEY="$SALAD_AI_GATEWAY_API_KEY"
```

These tool-specific variables contain the same AI Gateway key set in Quick Start, not an account API key or an OpenAI
API key.

## Why Salad AI Gateway?

- **No Infrastructure** - no container groups to deploy, no replicas to manage, no cold starts to worry about
- **Always on** - our distributed GPU network ensures high availability and reliability
- **OpenAI-compatible** - easy integration with any OpenAI-compatible tool
- **SaladCloud Pricing** - 90% cost savings vs traditional providers
- **Data Privacy** - your data is never used for training
- **Powered by Sustainable Computing** - utilizing otherwise wasted GPU resources to reduce carbon footprint
