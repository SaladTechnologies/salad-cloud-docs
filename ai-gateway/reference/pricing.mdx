## Pay-Per-Token Billing

Self-service AI Gateway access uses pay-per-token billing. Usage is charged for input and output tokens at the published
rates below, with no concurrency limit.

Each AI Gateway key belongs to one user and one organization. Usage is billed to the organization associated with the
key and draws from that organization's SaladCloud credit balance. The organization must have a **positive credit
balance** when a request is admitted. Follow [Pay-Per-Token Onboarding](/ai-gateway/tutorials/pay-per-token-onboarding)
to add credits and create an organization-specific AI Gateway API key.

Requests already admitted are allowed to complete and their tokens are billed even if credits run out during generation.
New requests are rejected with `402 credits_exhausted` once the credit balance is no longer positive. Likewise, revoking
or regenerating a key does not cancel or remove charges for requests already admitted. See
[key lifecycle behavior](/ai-gateway/how-to-guides/manage-api-key#requests-already-in-progress).

See [Errors](/ai-gateway/reference/errors) for suggested actions and safe retry behavior.

## Closed Beta

The existing allowlisted closed-beta path remains a separate access option with a flat monthly fee and no per-token
charges under that plan. It does not require self-service pay-per-token enrollment. Contact
[SaladCloud Support](/support/contact) about your existing plan or access.

The rates below apply to pay-per-token requests, not to usage covered by the closed-beta flat-rate plan. See
[Access Model](/ai-gateway/explanation/overview#access-model) for the two paths.

## Pay-Per-Token Rates

Prices are per million tokens.

| Model             | Input ($/M tokens) | Output ($/M tokens) |
| :---------------- | -----------------: | ------------------: |
| `qwen3.6-35b-a3b` |              $0.06 |               $0.95 |
| `qwen3.5-35b-a3b` |              $0.07 |               $0.94 |

Input tokens include your prompt, image inputs, tool definitions, and any conversation history sent with each request.
Output tokens are the generated response.
