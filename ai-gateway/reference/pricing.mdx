## Pay-Per-Token Billing

Salad AI Gateway uses pay-per-token billing. Usage is charged for input and output tokens at the published rates below,
with no concurrency limit.

Usage draws from your organization's SaladCloud credit balance. Follow
[Pay-Per-Token Onboarding](/ai-gateway/tutorials/pay-per-token-onboarding) to add credits and create an
organization-specific AI Gateway API key.

## Pay-Per-Token Rates

Prices are per million tokens.

| Model             | Input ($/M tokens) | Output ($/M tokens) |
| :---------------- | -----------------: | ------------------: |
| `qwen3.6-35b-a3b` |              $0.06 |               $0.95 |
| `qwen3.5-35b-a3b` |              $0.07 |               $0.94 |

Input tokens include your prompt, image inputs, tool definitions, and any conversation history sent with each request.
Output tokens are the generated response.
