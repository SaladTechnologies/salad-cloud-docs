## Payment Options

| Option               | Billing                             | Concurrent requests  | Availability                                                              |
| :------------------- | :---------------------------------- | :------------------- | :------------------------------------------------------------------------ |
| Monthly subscription | Flat monthly rate                   | 2                    | [Contact Support](/support/contact)                                       |
| Pay per token        | Per million input and output tokens | No concurrency limit | [Self-service onboarding](/ai-gateway/tutorials/pay-per-token-onboarding) |

The monthly subscription is a flat-rate option with a limit of two concurrent requests. Contact SaladCloud Support to
request the plan and discuss subscription pricing.

Pay-per-token billing does not have the monthly subscription's concurrency limit. Usage is billed at the published input
and output rates.

## Pay-Per-Token Rates

Prices are per million tokens.

| Model             | Input ($/M tokens) | Output ($/M tokens) |
| :---------------- | -----------------: | ------------------: |
| `qwen3.6-35b-a3b` |              $0.09 |               $0.60 |
| `qwen3.6-27b`     |              $0.30 |               $1.20 |
| `qwen3.5-35b-a3b` |              $0.08 |               $0.65 |
| `qwen3.5-9b`      |              $0.06 |               $0.09 |

Input tokens include your prompt, image inputs, tool definitions, and any conversation history sent with each request.
Output tokens are the generated response.
